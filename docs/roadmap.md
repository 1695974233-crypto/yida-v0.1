# 产品路线图

## v0.1：概念与关键交互验证

状态：已完成。

- 移动端产品原型。
- 用户偏好引导。
- 虚拟衣柜。
- 持久化数据。
- 规则搭配推荐。
- 场景选择。
- 对话式需求入口。
- 脏衣篓和反馈。
- 产品、Agent、RAG 和技术文档。

目标：让产品概念可以被演示、讨论和继续开发。

## v0.2：真实衣柜

- [x] 图片对象存储。
- [x] 真实衣物上传。
- [x] AI 属性识别接口与无密钥回退。
- [x] Seedream 展示图整理接口。
- [x] 用户确认和修改标签。
- [x] 公开体验期每位访客每天最多识别 10 次。
- [ ] 正式用户测试前根据预算和真实用量提醒产品负责人调整或解除每日 10 次限制。
- [ ] 独立的确定性自动抠图。
- [ ] 更完整的图片质量检测。
- 重复衣物识别。

目标：用户能录入至少 10 件真实衣服。

## v0.3：真实环境与 AI 对话

- 定位授权和手动城市。
- 真实天气 API。
- 多模态大模型对话。
- 长期画像与当天临时要求分离。
- 对话式单品替换。
- 推荐原因和不确定性说明。

目标：推荐能够可靠反映真实天气和复杂表达。

## v0.4：早期用户测试

- 邀请 20～30 位目标用户。
- 完整行为埋点。
- 推荐曝光与采纳漏斗。
- 点踩原因。
- 衣柜录入漏斗。
- 7 天留存实验。
- 人工穿搭顾问参与的服务型验证。

目标：证明用户会连续使用，并把推荐穿出门。

## v0.5：个性化学习

- 风格与颜色偏好分数。
- 历史成功搭配召回。
- 衣物利用率和重复穿着控制。
- 探索与利用策略。
- 规则权重自动调优。
- 衣柜分析和低频衣物激活。

目标：让同一天、同一天气下的不同用户获得明显不同的推荐。

## v0.6：发现与内容库

- 授权内容导入。
- 风格、场景和搭配公式提取。
- 多模态向量检索。
- 喜欢、不感兴趣和收藏闭环。
- 将外部穿搭映射到个人衣柜。

目标：发现页服务于个人衣柜，而不是成为独立内容社区。

## v0.7：AI 试穿

- AI 模特试穿。
- 本人试穿。
- 身份和衣物细节保持评测。
- 生成内容标识。
- 成本、延迟和失败降级。

目标：验证试穿能否提升搭配采纳，而不只是增加分享。

## v1.0：公开产品准备

- 正式用户体系。
- 隐私影响评估。
- 删除、导出和授权管理。
- 内容审核和版权机制。
- 安全、限流、监控和灾备。
- 根据付费方案、用户体系和反滥用能力解除或分层调整体验期限流。
- 推荐效果评测。
- 应用商店或小程序发布准备。

## 单人开发建议

一个人开发时的优先级：

1. 先证明用户愿意录入衣柜。
2. 再证明推荐会被穿出门。
3. 再提高 AI 自动化程度。
4. 最后扩展发现、试穿和商业化。

不要同时训练推荐模型、虚拟试穿模型和内容算法。
